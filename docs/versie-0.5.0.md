# Media Monster 0.5.0

Deze release voegt een centraal instellingenvenster toe via het tandwiel rechtsboven.

- Verbinding wijzigen zonder permanente knop op het dashboard.
- Veilig uitloggen: lokaal API-token, achtergrondcontrole en pushregistratie worden verwijderd.
- Drie lampkleurpaletten: Monster, Helder en kleurenblindvriendelijk.
- Optioneel AMOLED-zwart thema.
- Opslagkaarten en statusregels per container afzonderlijk tonen of verbergen.
- Containers sorteren op A–Z, Z–A of de volgorde van het NUC-configuratiebestand.
- Meldingen voor containerproblemen en updates beheren.
- Echte Firebase-testmelding vanuit de instellingen.
- Diagnose met appversie, Dockerstatus en pushregistratie.
