# Media Monster 0.5.2

- Een wachtwoord moet minimaal 8 tekens bevatten.
- Een wachtwoord moet minimaal 1 letter en 1 cijfer bevatten.
- De app toont deze regel onder beide wachtwoordvelden.
- De server en de Android-app controleren exact dezelfde regel.
- 36 server- en beveiligingstests slagen op de NUC.
- APK-versie: 0.5.2, versiecode 11.
